# BrewCult wordmark & lockups — Phase 4

Typeface: Space Grotesk (SIL Open Font License 1.1), Medium + Bold. All deliverables are
OUTLINED paths — no font installation needed by any vendor, ever. Do not retype the name
in live text for logo use; use these files.

## Naming treatments
- BREWCULT (compact, dual-weight: BREW in Medium, CULT in Bold) — the official product and
  company treatment. Tracking 0.09em. Use everywhere by default.
- BREW / CULT (stacked, all Bold, tracking 0.30em, core mark centered between the words) —
  editorial and merchandise composition ONLY. Never the app name, never legal use.

## Files
- brewcult-wordmark(.svg/-reversed.svg) — standalone wordmark, espresso / cream.
- brewcult-lockup-horizontal.svg — mark + wordmark; primary lockup for web headers, docs.
- brewcult-lockup-vertical.svg — mark above wordmark; square-ish placements.
- brewcult-lockup-stacked.svg — the ceremonial merch composition (sun rises between the words).
- 2048px PNG masters of each in /png.

## Rules
1. All core-mark golden rules apply inside lockups (never close the flat cut or the gap).
2. Never re-space, re-weight, or set CULT lighter than BREW — the emphasis is the wink.
3. Minimum sizes: horizontal lockup 120px wide; standalone wordmark 90px; below that, use the
   core mark alone.
4. Clear space: cap height on all sides of any lockup.
5. Colors: espresso #3B2A20 / cream #F4EDE3 only, straight swap for reversed.
