# BrewCult community badge — Variant A (ceremonial)

Relationship: B = identity (core mark), A = the identity in ceremonial dress.
Everything outside the core mark is a removable costume: outer border (r228, 16-unit stroke),
saucer bar, and the congregation — eight upright miniature truncated suns (r22, cut at 4/5 radius,
190 units from center, one at 12 o'clock). Strip them and the untouched core mark remains.

Rules
1. The core mark inside the badge is the exact locked geometry — never redrawn, never re-proportioned.
2. All golden rules from USAGE.md apply inside the badge, including: never close any flat cut.
3. The saucer exists ONLY here. It never migrates into the core mark.
4. Embroidery: every element is a solid satin block or bold border; minimum feature 14 units. Use
   badge-patch-3in-900.png for 3" patches, badge-patch-15in-450.png for 1.5".
5. Sticker/die-cut: the SVG is transparent outside the cream disc — cut line = disc edge (r236).
6. Reversed (cream on espresso) for dark garments and dark bag stock.
